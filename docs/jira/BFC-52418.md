## Specificaitons

### 1. Name Number

**Name Number:** a number from 1-9 derived from the user's first name.

Convert each letter to its alphabetical position:

`A = 1, B = 2, C = 3 ... Z = 26`

Add all values and reduce the total until one number from 1-9 remains.

Example:

`Marius → 13+1+18+9+21+19 = 81`

`81 → 8+1 = 9`

**Name Number = 9**.

### 2. Life Path Number

**Life Path Number:** a number from 1-9 derived from all digits in the user's complete date of birth.

Example:

`08/01/1986`

`0+8+0+1+1+9+8+6 = 33`

`33 → 3+3 = 6`

**Life Path Number = 6**.

### 3. Zodiac information

Determine the Zodiac sign from the month and day of birth using the **Zodiac Date Range** lookup table.

Use the Zodiac sign to retrieve:

* Zodiac Lucky Day(s)
* Zodiac Lucky Numbers

### 4. Date Number Total

**Date Number Total:** the sum of every digit in the evaluated date before the value is reduced.

Example:

`22/02/2025`

`2+2+0+2+2+0+2+5 = 15`

**Date Number Total = 15**

Keep this value because a two-digit Zodiac lucky number may match it directly.

### 5. Date Numerology Number

**Date Numerology Number:** the Date Number Total reduced to a number from 1-9.

Example:

`15 → 1+5 = 6`

**Date Numerology Number = 6**.

### 6. Name Score

**Name Score:** points awarded according to the numerical distance between the Name Number and Date Numerology Number.

Maximum: **2 points**

`Difference = |Name Number - Date Numerology Number|`

| Difference | Score |
| --- | --- |
| Exact match | 2 |
| 1 apart | 1.5 |
| 2 apart | 1 |
| 3 or more apart | 0.5 |

_The numbers are treated as a straight scale from 1 to 9._

### 7. Life Path Score

**Life Path Score:** points awarded according to the relationship between the Life Path Number and Date Numerology Number.

Maximum: **3 points**

Use the Life Path Compatibility lookup table. _(see refrence table below)_

| Relationship | Score |
| --- | --- |
| Compatible | 3 |
| Neutral | 2 |
| Unfavourable | 1 |

### 8. Lucky Day Score

**Lucky Day Score:** points awarded according to how close the evaluated weekday is to the user's Zodiac lucky day.

Maximum: **3 points**

The week is circular.

| Distance | Score |
| --- | --- |
| Exact lucky day | 3 |
| 1 day away | 2 |
| 2 days away | 1 |
| 3 or more days away | 0 |

_For signs with two lucky days, compare against both and use the closer one._

### 9. Lucky Number Score

**Lucky Number Score:** points awarded according to how closely today’s date values match the user’s Zodiac Lucky Numbers.

Maximum: **2 points**

Compare using:

* **Date Numerology Number**
* **Date Number Total**
* **Reduced versions of the Zodiac Lucky Numbers**

| Result | Score |
| --- | --- |
| Exact match | 2 |
| Date Numerology Number is one away from a reduced Zodiac Lucky Number | 1 |
| No match | 0 |

This is more precise than the current wording, which could make a developer apply the “one away” rule to the wrong values.

---

### 10. Luck Score

**Luck Score:** the total points produced by the four scoring rules before today is compared with the rest of the year.

`Luck Score = Name Score + Life Path Score + Lucky Day Score + Lucky Number Score`

Maximum = **10**.

So from this point onward, use **Luck Score everywhere**, including the full-year calculation and ranking.

---

### 12. Annual Ranking

**Annual Rank:** the position of a date after all dates in the year are ordered from strongest to weakest.

**Primary rule:**

**Higher Luck Score = stronger date**

If two dates have the same Luck Score, compare them in this order:

1. Higher Lucky Day Score
2. Higher Lucky Number Score
3. Higher Life Path Score
4. Higher Name Score
5. Earlier calendar date

Each rule is used only when all previous values are equal.

> The tie-break determines the ranking order only and does not change the Luck Score.

> The developer may implement the tie-break using any technical method, provided this exact priority order and resulting ranking are preserved.

This captures what we established from your spreadsheet: the combined numeric ranking formula is **one implementation**, not a mandatory requirement.

### 14. Final Luck Category & Final Luck Score

First determine the **Final Luck Category** from the Annual Luck Position:

| Annual Luck Position | Final Luck Category | Final Luck Score Range |
| --- | --- | --- |
| `85%–100%` | Jackpot Luck | 7.01–10.00 |
| `50%–<85%` | Good Luck | 5.01–7.00 |
| `15%–<50%` | Some Luck | 3.01–5.00 |
| `0%–<15%` | Low Luck | 1.00–3.00 |

For a normal 365-day year:

| Annual Rank | Final Luck Category |
| --- | --- |
| 1–55 | Jackpot Luck |
| 56–183 | Good Luck |
| 184–310 | Some Luck |
| 311–365 | Low Luck |

Then calculate where the Annual Luck Position sits within that category:

| Final Luck Category | Position Minimum | Position Maximum |
| --- | --- | --- |
| Low Luck | 0.00 | 0.15 |
| Some Luck | 0.15 | 0.50 |
| Good Luck | 0.50 | 0.85 |
| Jackpot Luck | 0.85 | 1.00 |

`Position Within Category = (Annual Luck Position - Category Position Minimum) / (Category Position Maximum - Category Position Minimum)`

Then:

`Final Luck Score = Score Range Minimum + (Position Within Category × (Score Range Maximum - Score Range Minimum))`

Round the **Final Luck Score to two decimal places**.

* **Life Path Compatibility**: defines whether each Life Path Number and Date Numerology Number combination is Compatible, Neutral, or Unfavourable.

* **Zodiac Lucky Days**: provides the lucky day or days associated with each Zodiac sign.
* **Zodiac Lucky Numbers**: provides the lucky numbers associated with each Zodiac sign.
