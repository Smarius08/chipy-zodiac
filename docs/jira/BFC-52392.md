## Intro

Our tools are built 100% FE which exposes their logic to the web. This allowed competitions to easily copy the logic. We need to find a way to block this.

## Specifications

Please review tools from [https://chipy.com/tools](https://chipy.com/tools).

### Research

Perform a research on Google, ChatGPT etc on how this can be done. There are many companies that make their Apps using full FE. Im sure there are common methods they use so the games will not easily copiable.

### Implementation

After you do the research discuss with <custom data-type="mention" data-id="id-0">@Tan Tonor</custom>. Then we will decide on which way to go for.

We need the encryption method to:

* Be easily implemented on the existing code or with very small modifications
* Wont hurt the user experience (make it laggy, create bugs etc)
* Reliable and easy to manage
